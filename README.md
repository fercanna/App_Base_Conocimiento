# App Base de Conocimiento (Knowledge Management System)

## Objetivo del Proyecto
Desarrollar una herramienta digital diseñada para la gestión estratégica de activos intangibles, alineada con los requisitos de la norma **ISO 9001:2015**, específicamente en su **Punto 7: Apoyo**.

## Marco Teórico
La aplicación utiliza como guía técnica el modelo de profesionalización de la gestión del conocimiento de **AENOR**, estructurando la información en tres pilares fundamentales:

1. **Capital Humano:** Gestión de competencias, aptitudes y preservación del saber hacer (tácito).
2. **Capital Estructural:** Sistematización de procesos, lecciones aprendidas y bases de datos (explícito).
3. **Capital Relacional:** Flujo de conocimiento con el entorno (clientes, proveedores y aliados).

## Cumplimiento ISO 9001
- **7.1.6 Conocimientos de la Organización:** La App permite determinar, mantener y poner a disposición el conocimiento necesario para la operación de los procesos.
- **7.2 Competencia:** Evaluación de la eficacia de las acciones tomadas para adquirir la competencia necesaria.
- **7.5 Información Documentada:** Control, creación y actualización de los activos de conocimiento.

## Stack Técnico
- **Core:** Python
- **IA:** Gemini API (Modelos 1.5 Pro/Flash) para el procesamiento de lenguaje natural y auditoría de contenidos.
- **Control de Versiones:** Git / GitHub
