# App Base de Conocimiento (Knowledge Management System)

## Objetivo del Proyecto
Desarrollar una herramienta digital diseñada para la gestión estratégica de activos intangibles, alineada con los requisitos de la norma **ISO 9001:2015**, específicamente en su **Punto 7: Apoyo**.

## Marco Teórico
La aplicación utiliza como guía técnica el modelo de profesionalización de la gestión del conocimiento de **AENOR**, estructurando la información en tres pilares fundamentales:

1. **Capital Humano:** Gestión de competencias, aptitudes y preservación del saber hacer (tácito).
2. **Capital Estructural:** Sistematización de procesos, lecciones aprendidas y bases de datos (explícito).
3. **Capital Relacional:** Flujo de conocimiento con el entorno (clientes, proveedores y aliados).


## Metodología de Gestión Estratégica (Capítulo 2)
La App no se concibe como una herramienta aislada, sino como el soporte final de una secuencia lógica de diseño basada en los lineamientos de AENOR:

1. [cite_start]**Modelo:** Define el marco de referencia inicial para la organización[cite: 634].
2. [cite_start]**Estrategia:** Pone el foco en propósitos específicos según las necesidades y coyunturas cambiantes[cite: 635].
3. [cite_start]**Procesos:** Establece el esquema operativo que la App debe automatizar y seguir[cite: 636].
4. [cite_start]**Organización:** Configura los espacios, instrumentos y momentos necesarios para que el conocimiento fluya[cite: 637].
5. [cite_start]**Competencias:** Define el perfil profesional requerido para las personas que actúan en el sistema[cite: 638].
6. [cite_start]**Herramientas (La App):** Actúa como el soporte tecnológico final para potenciar la agilidad, adaptándose al nivel de madurez de la empresa y evitando el sesgo de la "sofisticación tecnológica" innecesaria.

> [cite_start]**Nota Técnica:** El desarrollo de esta plataforma prioriza la utilidad sobre la tecnología; la herramienta es un dinamizador de procesos estratégicos preexistentes[cite: 639, 707].

## Cumplimiento ISO 9001
- **7.1.6 Conocimientos de la Organización:** La App permite determinar, mantener y poner a disposición el conocimiento necesario para la operación de los procesos.
- **7.2 Competencia:** Evaluación de la eficacia de las acciones tomadas para adquirir la competencia necesaria.
- **7.5 Información Documentada:** Control, creación y actualización de los activos de conocimiento.

## Stack Técnico

- **IA:** Gemini API (Modelos 1.5 Pro/Flash) para el procesamiento de lenguaje natural y auditoría de contenidos.
